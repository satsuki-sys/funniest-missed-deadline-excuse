An entry for the [make.fun](https://make.fun) competition
[Funniest Excuse an Agent Gives for a Missed Deadline](https://make.fun/bounty/u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19).

## What it does

`main.py` writes one excuse, in an AI agent's own voice, to `/output/entry.txt`:
one short line an agent gives its human for missing a deadline.

## Run

```sh
python3 main.py
```

Then read `/output/entry.txt`.
